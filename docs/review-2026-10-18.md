# Viewer reliability review — 18 October 2026

Implementation and local validation on `0.8.0-beta1`, following the application review of images 539 and 14006 and plate image 1124.

## Resulting behavior

- Fresh openings use deterministic native-resolution automatic contrast. File display windows remain metadata. Saved ranges are restored exactly, including values outside sampled limits; the numeric inputs, sliders, renderer and saved URL agree.
- Contrast records automatic, restored or manual provenance. Statistics are refreshed independently for the selected field, render mode, projection, Z, T, quality and visible channels. Loading or stale statistics cannot be applied with Auto/Fit. Mode, engine, field and playback changes preserve the active contrast, including one shared range across plate fields.
- Contrast sampling reads at most 262,144 finite pixels per channel, through at most 16 tiles or five bounded native planes. It never calls `getVolume()`. Signed, floating, constant, empty and non-finite data have regression coverage.
- The shared physical position and units per screen pixel convert between 2D, Viv and Neuroglancer at voxel centers. Named-axis transform composition includes group transforms, translations, unit normalization and pyramid fallback ratios; engine rotations remain independent. Viv's volume target follows the same position as its sections. Fresh 3D openings and Reset fit the current panel layout and update this shared navigation, so returning to 2D retains the fitted physical scale.
- Each selected field resolves its own channels, labels and calibration, including composite stores. Label settings carry across matching layer names/paths rather than unrelated layer IDs. Overview label controls are disabled with an explanation and return when opening a field.
- Thumbnail scale calculations use their actual displayed width. One overview scale is shown only when all displayed fields have compatible measured calibration.
- Projection results share a 64 MiB LRU budget. The existing 200 MiB volume and 64 MiB preview budgets remain. Requests retain independent consumers: cancelling one view preserves other consumers, while cancelling the last stops downloads, polling and preview batches. Immediate replacement requests cannot be removed by an older cancelled request.
- Playback schedules one next frame after the visible frame is ready. A minimap or a single label/orthogonal panel cannot prematurely release playback. Synthetic frame, crop, color and timing fixtures cover this behavior.
- Failed derived volume and mesh jobs require an explicit authenticated retry. Polling does not repeatedly reset failures. Neuroglancer contexts expire and allow 32 live views per session, with atomic cross-worker updates and a readable capacity error instead of silent eviction.
- Viewer-generated PNG and movie labels use the live instance-color hash. Explicit colors and legacy recipe palettes are preserved. Label grids are aligned through physical coordinates for inspection and exports; heterogeneous gallery panels resolve metadata independently.
- Invalid optional saved channel, label and overlay entries are ignored. Unexpected render failures have a recovery action to reopen without saved settings.

Scientific images, original metadata and labels were not modified or generated during this review.

## Metadata interface

`GET /biomero_zarr_viewer/api/images/<id>/metadata/` accepts:

| Parameter | Behavior |
| --- | --- |
| `field` | A declared image field; defaults to the initial field. |
| `section=summary` | Default. Selected image, calibration, label and plate/well metadata, plus OMERO metadata. It does not scan sibling fields. |
| `section=nodes` | On-demand hierarchy page. |
| `section=omero` | OMERO metadata without hierarchy browsing. |
| `cursor` | Signed continuation bound to the store/routes and selected field; expires after 15 minutes. |

Hierarchy pages stop at 100 nodes, 8 MiB including duplicated attribute/document representations, or approximately two seconds of traversal. The existing document and hierarchy limits, authentication and path checks remain. `next_cursor` and notices report continuation or truncation. Arrays are terminal nodes: metadata browsing never descends into pixel chunks. A summary may offer remaining selected-field metadata through its continuation if a budget is reached.

The popup searches **loaded metadata**, offers additional pages on demand, cancels requests when closed or the field changes, retains loaded pages when retrying a page, and clamps back into the viewport after resize. Worker/HTML failures show a readable retry message.

Measured through the authenticated Docker proxy on the existing public 3D image 14006. Each row is one paired cold/cached run with one intensity channel and three explicitly selected objects from the original label layer. “Cold” resets only this image's derived application cache; the OS/filesystem cache was not flushed. Times include HTTP, local filesystem and polling overhead and are not GPU render benchmarks.

Transport was direct Zarr in every run. Cold native-level label derivation used approximately 803 KiB of cache, rather than preparing a complete intensity volume. Proxy logs for the fresh Neuroglancer contrast check recorded **zero `/volume/` requests**. Viv still uses bounded packed volumes when its renderer needs them.

Metadata summary timings across two requests were 1.25–1.34 s for image 539, 1.21–1.32 s for image 14006, and 2.86–2.89 s for plate 1124. The plate summary was approximately 35 KiB; its first bounded hierarchy page took 2.53–2.55 s. This replaces the previously reproduced worker timeout.
